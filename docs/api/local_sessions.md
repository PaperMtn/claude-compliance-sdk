# Local sessions

Sessions your users run in Claude apps on their own machines: Cowork in
Claude Desktop, Claude Code, Claude Science, and Claude for Microsoft
365. For Cowork sessions that run in Anthropic-managed cloud
environments, see [Remote sessions](remote_sessions.md).
